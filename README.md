# SporeCoop

Кооперативный мод для **Spore + Galactic Adventures (GOG)** и фреймворк **SporeKit**,
через который мод встраивается в игру. Всё собирается на Linux (llvm-mingw) и
тестируется в Bottles (Wine).

| Компонент | Что это | Где |
|---|---|---|
| `steam_api.dll` (loader) | прокси-DLL: игра сама её грузит, она поднимает SporeKit | `loader/` |
| `sporekit.dll` | рантайм модов: символы, хуки, кадр, консоль, горячая перезагрузка, оверлей | `sporekit/` |
| `coop.dll` | сам кооп-мод | `mods/coop/` |
| `sporectl` | CLI для управления запущенной игрой (тесты, RE, скриншоты) | `tools/sporectl.py` |
| `spore.sh` | деплой/запуск в Bottles/профили/фикстуры/логи | `tools/spore.sh` |
| `addrport` | перенос адресов ModAPI на этот exe, «оконные» exe для REA | `tools/addrport/` |
| `fakepeer.py` | фейковый игрок по сети для тестов без второго экземпляра | `tools/fakepeer.py` |
| `package.sh` | zip для установки другу (Windows/Wine) | `tools/package.sh` |

Документация — в [`docs/`](docs/README.md).

## Быстрый старт (разработка)

```bash
make && make test                 # собрать всё + юнит-тесты сети на Linux
tools/spore.sh install            # один раз: поставить прокси steam_api.dll в игру
tools/spore.sh deploy             # скопировать свежие DLL/символы/конфиги в игру
tools/spore.sh run -p test        # запустить игру в Bottles с тестовым профилем (окно, свои сейвы)
tools/sporectl.py info            # проверить, что SporeKit жив
tools/sporectl.py shot            # скриншот в out/shots/
make coop && tools/spore.sh deploy && tools/sporectl.py mod.reload coop   # горячая перезагрузка
python3 tools/tests/coop_two_instances.py                                # полный тест: 2 копии игры (Существо)
python3 tools/tests/coop_mode.py --fixture space --planet Game0/Maraya     # тест любого режима по фикстуре
python3 tools/tests/coop_ui.py                                           # тест интерфейса: меню → лобби → игра
```

## Как играть

1. Хост: главное меню → **Co-op** → имя → **Host**, затем загружает сохранение или начинает игру.
   В окне видны адреса, которые нужно сообщить друзьям.
2. Гость: главное меню → **Co-op** → имя → щелчок по игре из списка «Games on your network»
   или адрес хоста → **Join**. Мир хоста приходит и загружается сам, гость оказывается рядом
   (в космосе хост должен быть вне планеты, чтобы игра разрешила сохранение).
3. В игре **F9** открывает лобби: игроки, этап, пинг, готовность, чат, «Send my world», «Leave».

То же доступно в консоли читов (`Ctrl+Shift+C`): `coop name Алиса`, `coop host`,
`coop join <ip>`, `coop status`, `coop say <текст>`, `coop ping`, `coop leave`.
В Приключениях каждый запускает то же приключение сам. Через интернет порт UDP 47810 у хоста
должен быть доступен (проброс порта на роутере или VPN вроде ZeroTier / Radmin VPN / Tailscale).
